AI AutoML Analyst

폴더 안 CSV를 탐색하고, 선택한 CSV/target 컬럼 기준으로 ML 모델 실험 결과를 비교하는 분석 보조 도구입니다.

1. 폴더 스캔

로컬 폴더 경로를 입력하면 하위 CSV 파일을 탐색하고, 컬럼 구성이 같은 CSV끼리 schema 그룹으로 묶습니다.

2. CSV 유형 목록

각 schema 그룹은 컬럼 구성이 같은 CSV 묶음입니다. 대표 파일은 그룹 안의 일부 CSV 예시이며, 현재 분석은 사용자가 선택한 CSV 파일 1개만 실행합니다. 여러 CSV를 병합한 최종 모델링은 후속 분석 단계에서 별도로 수행해야 합니다.

3. 선택한 CSV 분석

아래 분석은 선택한 CSV 파일 1개와 선택한 예측 대상 컬럼을 기준으로 실행됩니다. 결과는 최종 결론이 아니라, 데이터 구조와 모델 실험 가능성을 확인하기 위한 탐색적 결과입니다.

예시:
- 분류: 당뇨 여부, 구매 여부, 연체 여부, 상권 변화 등급, 콘텐츠 카테고리
- 회귀: 매출 금액, 지출 총금액, 유동인구 수, 점포 수, 시청 시간, 가격
주의: 현재 분석은 선택한 CSV 파일 1개만 실행합니다. 같은 schema 그룹의 여러 CSV를 자동 병합하지 않습니다. 매출/금액/건수/인구/점포수 같은 집계형 컬럼을 target으로 선택할 경우, 같은 계열의 파생 컬럼이 feature에 포함되어 성능이 비정상적으로 높게 나올 수 있습니다.
중단 버튼은 브라우저 요청을 취소합니다. 이미 서버에서 시작된 작업은 잠시 더 실행될 수 있습니다.
